# يلا نسافر

دليل سفر ومجتمع للمسافرين السعوديين والخليجيين: اكتشف أماكن، خطط رحلتك مع شلتك، ورتّب كل شي من أول فكرة لين ترجع.
**التطبيق ما فيه حجز ولا دفع.**

| الجزء | المجلد | التقنية |
|---|---|---|
| التطبيق (آيفون، أندرويد، ويب) | `/` | Expo SDK 57 + React Navigation + TypeScript |
| لوحة التحكم (ويب) | `admin/` | Vite + React + Tailwind v4 |
| السيرفر | `supabase/` | Postgres + RLS + Edge Functions |
| التصاميم والمواصفات | `yalla-handoff/` | المرجع اللي انبنى عليه كل شي |

---

## التشغيل بسرعة (وضع العرض، بدون أي إعداد)

```bash
npm install
npx expo start          # امسح الـ QR بتطبيق Expo Go، أو اضغط w للويب
```

بدون إعدادات Supabase يشتغل التطبيق **بوضع العرض**:
- بيانات تجريبية كاملة: رحلة العلا بعد 9 أيام، إجازة جدة اللي انتهت، الشلة، المحادثات، الأماكن.
- كل شي محفوظ على الجهاز ويشتغل بدون إنترنت.
- لمعاينة «وضع اليوم» (الرئيسية أثناء الرحلة): **حسابي ← الإعدادات ← وضع العرض ← معاينة وضع اليوم**.

لوحة التحكم بوضع العرض:

```bash
cd admin && npm install && npm run dev     # http://localhost:5173
```

## ربط السيرفر (Supabase)

1. سوّ مشروع على [supabase.com](https://supabase.com).
2. طبّق قاعدة البيانات:
   ```bash
   npx supabase link --project-ref <ref>
   npx supabase db push            # يطبّق supabase/migrations
   psql "$DATABASE_URL" -f supabase/seed.sql   # المدن والدول الأولية (اختياري)
   ```
3. الأسرار والدوال:
   ```bash
   npx supabase secrets set ANTHROPIC_API_KEY=... GOOGLE_PLACES_API_KEY=...
   npx supabase functions deploy guide
   npx supabase functions deploy places-search
   ```
4. انسخ `.env.example` إلى `.env` في الجذر، وحط فيه `EXPO_PUBLIC_SUPABASE_URL` و `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
5. انسخ `admin/.env.example` إلى `admin/.env`، وحط فيه `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
6. **أول مشرف:**
   - سجّل دخول بالتطبيق مرة.
   - شغّل هذا الأمر من SQL Editor في Supabase:
     ```sql
     update profiles set is_admin = true where id = '<your-user-id>';
     ```
7. **تسجيل الدخول:**
   - **البريد:** فعّل Email OTP من Authentication.
   - **Apple و Google:** فعّل الـ Providers، وأضف `yallansafer://auth` في Redirect URLs.

## وش موجود

**التطبيق** (كل الأقسام في `yalla-handoff/SPEC.md`):

**الدخول والبداية**
- تسجيل الدخول: Apple وGoogle ورمز البريد والزائر.
- 3 أسئلة بعد أول دخول.

**الرئيسية**
- تتغيّر حسب حالتك: جديد، عندك رحلة قادمة، أثناء الرحلة، أو رجعت من رحلة.
- **وضع اليوم** فيه:
  - «اطلع خلال X دقيقة».
  - أوقات الصلاة وأقرب مسجد والقبلة (حساب أم القرى).
  - الطقس والطوارئ والمستندات.

**الاكتشاف**
- اكتشف: مختارة لك مع سبب الاقتراح، يصير هالويكند، الوجهات.
- النتائج: فلاتر للمفتوح الآن والعائلي والحلال والكرسي المتحرك والسعر، وتبديل بين القائمة والخريطة.
- بحث موحّد عن الأماكن والمدن والمسافرين والمنشورات.
- صفحة المكان: أزرار سريعة، تقييمات اللي تتابعهم أول، و«أضف لرحلتي».
- صفحة المدينة: أفضل وقت بالأشهر، تقييمنا وتقييم Google، والمسافرين هالشهر.

**التخطيط**
- رحلة جديدة بثلاث أسئلة، والدليل يقترح جدول مبدئي.
- صفحة الرحلة:
  - **الجدول:** يوم بيوم، صباح وغداء وعشاء، وقت المشوار بين الأماكن، وكشف التعارض.
  - **الميزانية:** بعملات متعددة والتسوية.
  - **التجهيز:** مع مسؤول لكل مهمة، وقائمة مقترحة حسب الوجهة.
  - **الأدوار:** منظّم وعضو ومشاهد.
- خريطة اليوم، و«افتح المسار كامل في الخرائط».
- مستنداتي: طيران، سكن، تذاكر QR، ومستندات خاصة بـ Face ID. تصوير ورفع PDF.
- متى نسافر؟ تقويم يصوّت فيه كل عضو، والتطبيق يطلع أفضل موعد.
- الانضمام برمز الدعوة أو الرابط.

**الشلة والمجتمع**
- المحادثات: تقدر تشارك مكان، تسوي تصويت (الفائز ينضاف للجدول)، وتسجّل مصروف (ينزل في الميزانية).
- دليل السفر الذكي (Claude): خطة بالأيام، وزر «حوّلها لرحلة».
- حسابي والملف العام: متابعة ومراسلة، و«نلتقي؟» للي يتابعون بعض بس.
- المنشورات قصيرة: حتى 10 صور و500 حرف.
- المجتمعات بطلب وموافقة، مع البلاغات.

**بعد الرحلة**
- ملخص الرحلة، والتقييم السريع.
- نشر الجدول، و«انسخ الخطة».

**الهوية والإعدادات**
- الجواز والأختام والشارات (ثانوية)، وسجّل وصولك.
- الإشعارات مع أزرار تصرّف.
- الإعدادات: فاتح وداكن وتلقائي، التاريخ الهجري، محفظتي (برامج الولاء)، الخصوصية، مشاركة الموقع مع شخص موثوق، تصدير البيانات، حذف الحساب.
- تذكيرات محلية: قبل الرحلة بأسبوع وبيوم.

**لوحة التحكم:**
- نظرة عامة.
- الأماكن والمختارات (رائج، مختار، مُموَّل)، والاستيراد من Google Places.
- المدن، ولفتات الموسم، ومعلومات الدخول للدول.
- قبول ورفض المجتمعات، ومعالجة البلاغات.
- المستخدمين: توثيق، وخبير محلي، ومشرف.
- مفاتيح الدخل الثلاث (مطفية).

**السيرفر:**
- 28 جدول و66 سياسة RLS، ودوال للانضمام والإعجاب والمجتمعات والإحصائيات.
- مزامنة offline-first: آخر تعديل يفوز، والرسائل لحظية.

## اللي باقي قبل النشر في المتاجر

هذي أشياء تحتاج حسابات أو خدمات خارجية، أو كود أصلي ما ينبني من هنا:

| البند | الحالة |
|---|---|
| ودجت الشاشة الرئيسية و Live Activity (SPEC 22.17) | **ما انبنى.** يحتاج كود Swift/Kotlin أصلي عبر Config Plugin |
| تحويل إيميل الحجوزات لمستنداتي | الزر موجود، بس يحتاج خدمة استقبال بريد (مثل Postmark Inbound) ودالة تحلل الإيميل |
| إشعارات الدفع من السيرفر | التذكيرات المحلية شغّالة. إشعارات الدعوات والرسائل بين الأجهزة تحتاج Expo Push + دالة ترسلها |
| الطقس الحقيقي | الحرارة الحين ثابتة في بيانات المدن. تحتاج خدمة طقس |
| رفع الصور للتخزين | الصور تنحفظ على الجهاز. الرفع لـ Supabase Storage (المجلدات جاهزة) باقي |
| مشاركة الموقع المباشر | الإعداد والمدة والإيقاف موجودين، بس عرض موقعك على خريطة الشخص الثاني باقي |
| الخرائط على آيفون وأندرويد | `react-native-maps`. في أندرويد تحتاج مفتاح Google Maps في `app.json` |
| البناء والنشر | `npx eas build` ثم `npx eas submit` (يحتاج حساب Apple Developer و Google Play) |

## البنية

```
App.tsx                     المزوّدات، الروابط العميقة، النوافذ العامة
src/theme/                  الألوان (فاتح/داكن)، الخط، المقاسات، مزوّد المظهر
src/ui/                     مكوّنات الواجهة: Txt, Btn, Card, Sheet, Pill… (44px+، 12px+، تسميات لقارئ الشاشة)
src/components/             مكوّنات التطبيق: بطاقات الأماكن والرحلات، «أضف لرحلتي»، الجواز…
src/data/                   الأنواع، المخزن المحلي (zustand + AsyncStorage)، العمليات، القراءة، بيانات العرض
src/lib/                    المنطق: التعارض، التسوية، أفضل موعد، الصلاة، الدليل، المزامنة، الإشعارات
src/screens/                كل الشاشات
supabase/migrations/        قاعدة البيانات والصلاحيات
supabase/functions/         guide (Claude)، places-search (Google Places)
admin/                      لوحة التحكم
```

**قواعد مهمة للي يكمّل الشغل:**
- لا تكتب ألوان مباشرة. كل لون يجي من `useAppTheme().colors`، والنص الملوّن يستخدم `*Ink`.
- كل نص يمر عبر `<Txt>`.
- الشاشات ما تكتب في المخزن مباشرة. كل تعديل يمر عبر `src/data/actions.ts`.
- قبل أي كود Expo جديد، ارجع لتوثيق Expo 57 (`AGENTS.md`).
