# يلا نسافر: حزمة التصميم

## المحتوى

| الملف | وش فيه |
|---|---|
| `REVIEW.md` | **المراجعة:** الفجوات، احتياج كل نوع مسافر، اللي انضاف للنسخة الكاملة، معايير الجودة والقياس. |
| `SPEC.md` | المواصفات الكاملة: 24 قسماً (0 إلى 23) + قرارات المنتج، كل الصفحات، البيانات، القواعد، ترتيب التنفيذ. |
| `theme/native/tokens.ts` | **Expo:** الألوان (فاتح + داكن)، الخط، المقاسات، الحواف، الظلال. جاهز للنسخ. |
| `theme/native/ThemeProvider.tsx` | **Expo:** فاتح / داكن / تلقائي + تحميل الخط + RTL. جاهز للنسخ. |
| `theme/native/Text.tsx` | **Expo:** مكوّن النص الموحّد `<AppText>`. |
| `theme/web/` | نفس القيم بصيغة Tailwind، للوحة الإدارة على الويب فقط. |
| `mockups/profile.html` | حسابي + الملف العام |
| `mockups/explore.html` | اكتشف ← النتائج ← المكان ← أضف لرحلتي |
| `mockups/pages.html` | الرئيسية، رحلاتي، صفحة الرحلة، المحادثات، محادثة الشلة |
| `mockups/review.html` | إضافات المراجعة: رحلة جديدة، وضع اليوم، مستنداتي، خريطة اليوم، متى نسافر |
| `mockups/inner.html` | الدخول، المدينة، الوصول، الميزانية، التجهيز، الدليل، الإشعارات، الإعدادات، الدعوة |
| `yalla-design-handoff.pdf` | المراجعة + كل التصاميم بالفاتح والداكن + المواصفات |

- **التقنية:** React Native / Expo على آيفون وأندرويد والويب.
- **الإطلاق:** نسخة كاملة بكل الميزات (SPEC القسم 21).
- **الخط:** IBM Plex Sans Arabic (400 / 500 / 600 / 700).
- **المظهر:** فاتح، وداكن، وتلقائي (الافتراضي).

## انسخ هذا لـ Claude في المشروع الثاني

```
عندي حزمة تصميم في مجلد yalla-handoff/.
1. اقرأ yalla-handoff/REVIEW.md ثم yalla-handoff/SPEC.md كامل.
2. افتح ملفات yalla-handoff/mockups/*.html وارجع لها في الشكل (فيها زر فاتح/داكن).
3. التطبيق React Native / Expo (expo-router) لآيفون وأندرويد والويب.
   اقرأ القسم 0.1 (قرارات المنتج) و 0.2 (التقنية) أول.
4. ابدأ بالأساس: انسخ theme/native/ (tokens.ts و ThemeProvider.tsx و Text.tsx)،
   ركّب الخط IBM Plex Sans Arabic، فعّل RTL، وتأكد إن الوضع الداكن يشتغل.
5. ابنِ النسخة الكاملة (القسم 21) بترتيب البناء المكتوب هناك، وورّني النتيجة بعد كل خطوة.
   التطبيق ينطلق كامل، فلا تترك أي ميزة ناقصة أو شاشة «قريباً».
6. لا تضيف أي حجز أو دفع. التطبيق دليل سفر ومجتمع فقط.
7. طبّق قواعد السهولة (القسم 22.9) من أول يوم، وشرط الإطلاق: كل بند في القسم 23 ✅.
```
